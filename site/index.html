Pipeline

De un push a un comentario, en 4 pasos

Integración real de IA en un flujo de CI/CD, no un simple wrapper de un prompt.

01

PR abierta o actualizada

GitHub Actions dispara el workflow automáticamente en cada opened / synchronize.

02

Se obtiene el diff

El script pide el diff a la API REST de GitHub y lo trunca si es demasiado largo.

03

El LLM lo revisa

Se envía a Groq (Llama/GPT-OSS, gratis) pidiendo resumen, bugs y estilo — sin inventar problemas.

04

Comenta en la PR

La respuesta se publica con el GITHUB_TOKEN nativo de Actions. Cero credenciales extra.

Resumen

Se añade un nuevo módulo examples/stats.py que contiene dos funciones de utilidad: average para calcular la media de una lista de números y find_max para obtener el valor máximo.

Posibles bugs o problemas de lógica

  • Argumento mutable por defecto en average(numbers=[]). El mismo objeto lista se reutiliza entre llamadas, lo que puede producir resultados inesperados.
  • División por cero en average cuando la lista está vacía (len(numbers) == 0).
  • Suposición de lista no vacía en find_max: lanza IndexError con lista vacía.
  • Falta de validación de tipos en ambas funciones.

Sugerencias de estilo y buenas prácticas

  • Usar numbers=None y crear la lista dentro de la función.
  • Lanzar ValueError explícito ante listas vacías.
  • Usar sum() / max() nativos de Python en vez de bucles manuales.
  • Añadir docstrings y type hints.

Setup

Listo en menos de 5 minutos

Sin infraestructura propia, sin servidores que mantener.

  • 1

    Consigue una API key gratuita en console.groq.com — no requiere tarjeta de crédito.

  • 2

    Añádela como secreto del repo (GROQ_API_KEY) en Settings → Secrets → Actions.

  • 3

    Copia el workflow a .github/workflows/ — usa el GITHUB_TOKEN que Actions ya provee.

  • 4

    Abre una Pull Request. El bot comenta solo, en segundos.

# .github/workflows/pr-review.yml
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - run: python scripts/review_pr.py
        env:
          GROQ_API_KEY: ${{ secrets.GROQ_API_KEY }}
